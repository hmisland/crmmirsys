The WooCommerce integration brings the customers, orders, order items and ordered products of your WooCommerce shops into the CRM. The CRM only reads from the shop; it never changes anything there.

Before you start: the WooCommerce module must be active for your organization (see Organization settings › Modules › Modules & Features), and you need permission to edit organization settings.

1. Create API keys in WordPress

  1. In your WordPress admin open WooCommerce › Settings › Advanced › REST API and click Add key.
  2. Give it a description (for example “CRM”), choose a user and set Permissions to Read.
  3. Click Generate API key and copy the Consumer key (starts with ck_) and Consumer secret (starts with cs_). WordPress shows the secret only once.

2. Add the connection in the CRM

  1. Go to Organization settings › Manage integrations. On the WooCommerce card click Add a connection.
  2. Enter a Connection name (for example the shop’s name), the Store address starting with https://, and the two keys.
  3. Click Add connection, then Test connection. When the test succeeds the status becomes Connected.
  4. Click Sync now to start the first import.

Keys are stored encrypted and are never shown again. To change a key later, edit the connection and fill in only the field you want to replace; an empty key field keeps the saved value. One organization can connect up to 10 shops.

3. Webhooks (recommended)

With webhooks the shop tells the CRM about a new or changed order immediately. Without them, changes still arrive with the regular scheduled sync.

  1. On the connection card open Webhook settings and copy the Delivery URL and Secret.
  2. In WordPress open WooCommerce › Settings › Advanced › Webhooks › Add webhook.
  3. Set Status to Active, API version to WP REST API v3, and paste the Delivery URL and Secret.
  4. Create one webhook per topic: Order created, Order updated and, optionally, Customer updated.

Common test errors

  • WooCommerce rejected the keys — the key or secret is wrong, or the key has no Read permission.
  • The REST API was not found — check the store address, and that WordPress permalinks are not set to “Plain”.
  • The store could not be reached — the site is down or blocks the request (firewall or security plugin). It is retried automatically.

Tip: deleting a connection removes its imported customers and orders from the CRM only. Nothing changes in the shop. To pause a shop instead, use Disable.
