یکپارچه‌سازی ووکامرس، مشتریان، سفارش‌ها، اقلام سفارش و محصولات سفارش‌داده‌شدهٔ فروشگاه‌های ووکامرس شما را به CRM می‌آورد. CRM فقط از فروشگاه می‌خواند و هرگز چیزی را در آن تغییر نمی‌دهد.

پیش از شروع: ماژول ووکامرس باید برای سازمان شما فعال باشد (به تنظیمات سازمان › ماژول‌ها › ماژول‌ها و امکانات نگاه کنید) و باید اجازهٔ ویرایش تنظیمات سازمان را داشته باشید.

۱. ساخت کلیدهای API در وردپرس

  1. در پیشخوان وردپرس به ووکامرس › تنظیمات › پیشرفته › REST API بروید و روی افزودن کلید بزنید.
  2. یک توضیح وارد کنید (مثلاً «CRM»)، یک کاربر انتخاب کنید و دسترسی‌ها (Permissions) را روی خواندن بگذارید.
  3. روی ساخت کلید API (Generate API key) بزنید و کلید مصرف‌کننده (Consumer key) (که با ck_ شروع می‌شود) و رمز مصرف‌کننده (Consumer secret) (که با cs_ شروع می‌شود) را کپی کنید. وردپرس رمز را فقط یک بار نشان می‌دهد.

۲. افزودن اتصال در CRM

  1. به تنظیمات سازمان › مدیریت یکپارچه‌سازی‌ها بروید. روی کارت ووکامرس، افزودن اتصال را بزنید.
  2. یک نام اتصال (مثلاً نام فروشگاه)، نشانی فروشگاه که با https:// شروع می‌شود و دو کلید را وارد کنید.
  3. روی ثبت اتصال و سپس آزمایش اتصال بزنید. وقتی آزمایش موفق باشد، وضعیت به متصل تغییر می‌کند.
  4. برای شروع اولین دریافت، روی همگام‌سازی اکنون بزنید.

کلیدها رمزنگاری‌شده ذخیره می‌شوند و دیگر نمایش داده نمی‌شوند. برای تغییر یک کلید در آینده، اتصال را ویرایش کنید و فقط فیلدی را که می‌خواهید جایگزین شود پر کنید؛ فیلد کلیدِ خالی، مقدار ذخیره‌شده را حفظ می‌کند. هر سازمان می‌تواند حداکثر ۱۰ فروشگاه را متصل کند.

۳. وب‌هوک‌ها (توصیه‌شده)

با وب‌هوک‌ها، فروشگاه بلافاصله سفارش جدید یا تغییرکرده را به CRM اطلاع می‌دهد. بدون آن‌ها هم تغییرات با همگام‌سازی زمان‌بندی‌شدهٔ منظم می‌رسند.

  1. روی کارت اتصال، تنظیمات وب‌هوک را باز کنید و نشانی تحویل (Delivery URL) و کلید محرمانه (Secret) را کپی کنید.
  2. در وردپرس به ووکامرس › تنظیمات › پیشرفته › وب‌هوک‌ها › افزودن وب‌هوک بروید.
  3. وضعیت را روی فعال و نسخهٔ API را روی WP REST API v3 بگذارید و Delivery URL و Secret را جای‌گذاری کنید.
  4. برای هر رویداد یک وب‌هوک بسازید: سفارش ایجاد شد، سفارش به‌روز شد و در صورت تمایل مشتری به‌روز شد.

خطاهای رایج آزمایش

  • ووکامرس کلیدها را نپذیرفت — کلید یا رمز اشتباه است، یا کلید دسترسی خواندن ندارد.
  • REST API ووکامرس در این نشانی پیدا نشد — نشانی فروشگاه را بررسی کنید و مطمئن شوید پیوندهای یکتای وردپرس روی «ساده (Plain)» نیست.
  • در حال حاضر دسترسی به فروشگاه ممکن نشد — سایت از دسترس خارج است یا درخواست را مسدود می‌کند (دیوارهٔ آتش یا افزونهٔ امنیتی). به‌طور خودکار دوباره تلاش می‌شود.

نکته: حذف یک اتصال فقط مشتریان و سفارش‌های واردشدهٔ آن را از CRM پاک می‌کند و در فروشگاه چیزی تغییر نمی‌کند. برای توقف موقت یک فروشگاه، به‌جای حذف از غیرفعال‌سازی استفاده کنید.
