يجلب تكامل ووكومرس العملاء والطلبات وبنود الطلبات والمنتجات المطلوبة من متاجر ووكومرس الخاصة بك إلى نظام CRM. نظام CRM يقرأ من المتجر فقط؛ ولا يغيّر فيه أي شيء أبدًا.

قبل أن تبدأ: يجب أن تكون وحدة ووكومرس مفعّلة لمؤسستك (راجع إعدادات المؤسسة › الوحدات › الوحدات والميزات)، وتحتاج إلى صلاحية تعديل إعدادات المؤسسة.

1. إنشاء مفاتيح API في ووردبريس

  1. في لوحة إدارة ووردبريس افتح ووكومرس › الإعدادات › متقدم › REST API واضغط إضافة مفتاح.
  2. أعطه وصفًا (مثلًا «CRM»)، واختر مستخدمًا، واضبط الصلاحيات على قراءة.
  3. اضغط إنشاء مفتاح API وانسخ مفتاح المستهلك (Consumer key) (يبدأ بـ ck_) وسر المستهلك (Consumer secret) (يبدأ بـ cs_). يعرض ووردبريس السر مرة واحدة فقط.

2. إضافة الاتصال في نظام CRM

  1. انتقل إلى إعدادات المؤسسة › إدارة التكاملات. في بطاقة ووكومرس اضغط إضافة اتصال.
  2. أدخل اسم الاتصال (مثلًا اسم المتجر)، وعنوان المتجر بادئًا بـ https://، والمفتاحين.
  3. اضغط إضافة الاتصال، ثم اختبار الاتصال. عند نجاح الاختبار تصبح الحالة متصل.
  4. اضغط مزامنة الآن لبدء الاستيراد الأول.

تُخزَّن المفاتيح مشفّرة ولا تُعرض مرة أخرى. لتغيير مفتاح لاحقًا، عدّل الاتصال واملأ فقط الحقل الذي تريد استبداله؛ حقل المفتاح الفارغ يُبقي على القيمة المحفوظة. يمكن للمؤسسة الواحدة ربط ما يصل إلى 10 متاجر.

3. الـ Webhooks (موصى بها)

مع الـ Webhooks يُبلغ المتجرُ نظامَ CRM فورًا بأي طلب جديد أو معدَّل. وبدونها تصل التغييرات أيضًا مع المزامنة المجدولة المنتظمة.

  1. في بطاقة الاتصال افتح إعدادات Webhook وانسخ عنوان التسليم (Delivery URL) والمفتاح السري (Secret).
  2. في ووردبريس افتح ووكومرس › الإعدادات › متقدم › Webhooks › إضافة Webhook.
  3. اضبط الحالة على نشط، وإصدار API على WP REST API v3، والصق عنوان التسليم والمفتاح السري.
  4. أنشئ Webhook واحدًا لكل موضوع: تم إنشاء طلب، وتم تحديث طلب، واختياريًا تم تحديث عميل.

أخطاء الاختبار الشائعة

  • رفض ووكومرس المفاتيح — المفتاح أو السر خاطئ، أو ليس للمفتاح صلاحية القراءة.
  • لم يُعثر على REST API — تحقّق من عنوان المتجر، ومن أن الروابط الدائمة في ووردبريس ليست مضبوطة على «عادي».
  • تعذّر الوصول إلى المتجر — الموقع متوقف أو يحظر الطلب (جدار حماية أو إضافة أمان). تُعاد المحاولة تلقائيًا.

نصيحة: حذف الاتصال يزيل العملاء والطلبات المستوردة منه من نظام CRM فقط. لا يتغير شيء في المتجر. لإيقاف متجر مؤقتًا بدلًا من ذلك، استخدم تعطيل.
