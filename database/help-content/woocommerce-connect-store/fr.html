L'intégration WooCommerce importe dans le CRM les clients, les commandes, les articles de commande et les produits commandés de vos boutiques WooCommerce. Le CRM ne fait que lire la boutique ; il n'y modifie jamais rien.

Avant de commencer : le module WooCommerce doit être actif pour votre organisation (voir Paramètres de l’organisation › Modules › Modules et fonctionnalités), et vous devez avoir le droit de modifier les paramètres de l'organisation.

1. Créer des clés d'API dans WordPress

  1. Dans l'administration WordPress, ouvrez WooCommerce › Réglages › Avancé › API REST et cliquez sur Ajouter une clé.
  2. Saisissez une description (par exemple « CRM »), choisissez un utilisateur et réglez Droits sur Lecture.
  3. Cliquez sur Générer une clé d'API et copiez la Clé client (Consumer key) (commence par ck_) et le Secret client (Consumer secret) (commence par cs_). WordPress n'affiche le secret qu'une seule fois.

2. Ajouter la connexion dans le CRM

  1. Allez dans Paramètres de l’organisation › Gérer les intégrations. Sur la carte WooCommerce, cliquez sur Ajouter une connexion.
  2. Saisissez un Nom de la connexion (par exemple le nom de la boutique), l'Adresse de la boutique commençant par https://, et les deux clés.
  3. Cliquez sur Ajouter la connexion, puis sur Tester la connexion. Si le test réussit, le statut devient Connectée.
  4. Cliquez sur Synchroniser maintenant pour lancer le premier import.

Les clés sont stockées chiffrées et ne sont plus jamais affichées. Pour changer une clé plus tard, modifiez la connexion et remplissez uniquement le champ à remplacer ; un champ de clé vide conserve la valeur enregistrée. Une organisation peut connecter jusqu'à 10 boutiques.

3. Webhooks (recommandé)

Avec les webhooks, la boutique signale immédiatement au CRM une commande nouvelle ou modifiée. Sans eux, les changements arrivent quand même avec la synchronisation planifiée habituelle.

  1. Sur la carte de la connexion, ouvrez Paramètres du webhook et copiez l'URL de livraison et le Secret.
  2. Dans WordPress, ouvrez WooCommerce › Réglages › Avancé › Webhooks › Ajouter un webhook.
  3. Réglez l'état sur Actif, la version d'API sur WP REST API v3, et collez l'URL de livraison et le Secret.
  4. Créez un webhook par sujet : Commande créée, Commande mise à jour et, en option, Client mis à jour.

Erreurs de test fréquentes

  • WooCommerce a refusé les clés — la clé ou le secret est erroné, ou la clé n'a pas le droit Lecture.
  • L’API REST WooCommerce est introuvable — vérifiez l'adresse de la boutique, et que les permaliens WordPress ne sont pas réglés sur « Simple ».
  • La boutique est injoignable — le site est hors ligne ou bloque la requête (pare-feu ou extension de sécurité). Un nouvel essai a lieu automatiquement.

Astuce : supprimer une connexion retire ses clients et commandes importés du CRM uniquement. Rien ne change dans la boutique. Pour mettre une boutique en pause, utilisez plutôt Désactiver.
