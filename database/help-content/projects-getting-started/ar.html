إنشاء مشروع

افتح المشاريع ← مشروع جديد. أدخل الاسم ومدير المشروع وجهة اتصال أو شركة عند الحاجة وتاريخ البدء وتاريخ الانتهاء المتوقع. يُمنح رمز مثل PRJ-0001 تلقائيًا.

الحالات

  • مسودة ← مخطط ← نشط: التحضير وتنفيذ العمل.
  • متوقف: العمل موقوف مؤقتًا؛ استئناف يعيده نشطًا.
  • مكتمل: يُسجَّل تاريخ الانتهاء الفعلي؛ ويمكن إعادة فتحه.
  • ملغى: توقف العمل. المشاريع المكتملة والملغاة للقراءة فقط ولا تظهر متأخرة أبدًا.

الأعضاء

أضف الزملاء في الأعضاء. يرى الأعضاء المشروع حتى لو لم يسمح دورهم بذلك وحده؛ والتعديل يحتاج إلى صلاحية التعديل.

الروابط

يمكن ربط المشروع بالصفقات والعقود، وتعرض صفحات جهات الاتصال والشركات والصفقات والعقود مشاريعها. الملاحظات والوسوم والملفات وسجل كل تغيير أسفل صفحة المشروع.

نصيحة: حدِّد دائمًا تاريخ الانتهاء المتوقع؛ فلوحة المشاريع ورسائل التأخير تعتمد عليه.
