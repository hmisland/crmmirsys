Create a project

Open Projects → New project. Enter a name, the project manager, optionally a contact or company, the start date and the expected end date. A code such as PRJ-0001 is given automatically.

Statuses

  • Draft → Planned → Active: preparing and running the work.
  • On hold: paused; Resume makes it active again.
  • Completed: records the actual end date; it can be reopened.
  • Cancelled: stopped. Completed and cancelled projects are read-only and are never shown as late.

Members

Add colleagues under Members. Members can see the project even when their role would not otherwise allow it; editing still needs the edit permission.

Links

A project can be linked to deals and contracts, and contact, company, deal and contract pages show their projects. Notes, tags, files and the history of every change are at the bottom of the project page.

Tip: always set an expected end date — the dashboard and the delay emails use it.
