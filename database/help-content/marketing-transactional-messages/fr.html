Marketing › Transactionnels liste les messages unitaires que d'autres modules ont envoyés par les canaux du Marketing, par exemple les invitations aux enquêtes de satisfaction client. Les messages de campagne n'y figurent pas ; consultez la campagne et l'Historique des messages pour ceux-là.

Colonnes et filtres

  • Destinataire, Canal (SMS, e-mail, Bale), Source (quel module l'a envoyé et dans quel but), les heures Demandé et Envoyé le.
  • Filtrez par texte de recherche, canal, statut et source.

Statuts

StatutSignification
Envoi en coursEn cours de transmission au fournisseur.
Accepté par le fournisseurLe fournisseur a pris le message. Ce n'est pas encore une preuve de remise.
Nouvel essai prévuLe fournisseur était temporairement indisponible ; le message est renvoyé automatiquement.
ÉchecLe fournisseur l'a refusé, ou l'envoi a été interrompu. Le motif est affiché.
Non envoyéIgnoré volontairement : adresse invalide, destinataire désinscrit de ce canal, ou demande incomplète.

La colonne Remise indique si le message a atteint le téléphone ou la boîte de réception, uniquement quand le fournisseur le signale. « Non signalé » signifie qu'aucun rapport n'est encore arrivé. Exemples de rapports : Remis, Non remis, Rebond, Bloqué par le destinataire.

Pourquoi un message n'a pas été renvoyé

Si l'envoi a été interrompu en cours de route, le message est peut-être déjà parti. Pour éviter de l'envoyer deux fois, il n'est pas renvoyé automatiquement et s'affiche avec ce motif.

Astuce : les invitations de test aux questionnaires apparaissent avec la source « Enquête de satisfaction client (test) », pour les distinguer des vraies.
