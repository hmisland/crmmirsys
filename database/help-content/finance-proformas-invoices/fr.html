Règles du système

  • Une proforma est une offre de prix, pas une dette. Statuts : brouillon, envoyée, acceptée, refusée, expirée, convertie. Tant qu’elle n’est pas convertie, elle peut être modifiée ou supprimée.
  • La conversion crée une facture brouillon avec les mêmes lignes. La proforma devient « convertie », est verrouillée et ne peut être convertie qu’une fois.
  • Facture : brouillon → émise → (annulée). Un brouillon se modifie ou se supprime librement.
  • L’émission (en général réservée aux administrateurs de l’organisation) attribue le numéro suivant et fige la facture. Elle est refusée si la date de la facture tombe dans une période financière clôturée.
  • Une facture émise n’est jamais modifiée ; la correction se fait par un avoir.

Exemple : vous envoyez une proforma pour 3 licences. Le client accepte ; vous la convertissez, fixez l’échéance et l’émettez : INV-00007. À partir de ce moment, le montant vous est dû.

Conseil financier : une proforma n’est pas un chiffre d’affaires. Seule une facture émise crée une créance client. Indiquez toujours une échéance pour repérer les factures en retard.
