Open Organization settings › Messaging providers, card Email — Sender.

Fields

  • API token: the token from Sender (one piece, no spaces). Leave it empty later to keep the saved one.
  • Sender email: an address of your authenticated domain, e.g. news@yourdomain.com.
  • Sender name: what recipients see, e.g. your business name.
  • Reply-to: not supported by Sender's API — replies go to the sender email.

Buttons

  • Save and test connection: the token is checked with Sender before it is stored. If Sender rejects it, nothing is saved.
  • Test connection: re-checks the stored token; status and "last successful test" are updated.
  • Send test email: one real email to the address you type.
  • Disconnect: deletes the stored token; email campaigns using Sender stop.
