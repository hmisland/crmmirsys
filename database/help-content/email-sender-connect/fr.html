Ouvrez Paramètres de l'organisation › Fournisseurs de messagerie, carte E-mail — Sender.

Champs

  • Jeton API : le jeton de Sender (d'un seul bloc, sans espace). Laissez-le vide plus tard pour garder celui enregistré.
  • E-mail d'expéditeur : une adresse de votre domaine authentifié, ex. news@yourdomain.com.
  • Nom de l'expéditeur : ce que voient les destinataires, ex. le nom de votre activité.
  • Adresse de réponse : non prise en charge par l'API de Sender — les réponses arrivent à l'e-mail d'expéditeur.

Boutons

  • Enregistrer et tester la connexion : le jeton est vérifié auprès de Sender avant d'être stocké. Si Sender le refuse, rien n'est enregistré.
  • Tester la connexion : revérifie le jeton enregistré ; le statut et le « dernier test réussi » sont mis à jour.
  • Envoyer un e-mail de test : un vrai e-mail à l'adresse saisie.
  • Déconnecter : supprime le jeton ; les campagnes e-mail via Sender s'arrêtent.
