Une fois la boutique connectée, ses commandes arrivent dans le CRM de trois façons :

MoyenQuand
WebhookImmédiatement, quand la boutique signale une commande nouvelle ou modifiée (si les webhooks sont configurés).
Synchronisation planifiéeAutomatiquement toutes les 15 minutes : les commandes modifiées depuis la dernière synchronisation.
Synchroniser maintenantQuand vous cliquez dessus sur la carte de la connexion : la synchronisation est mise en file d'attente et s'exécute en arrière-plan en quelques minutes.

La première synchronisation d'une boutique importe les commandes des 30 derniers jours. Les commandes plus anciennes peuvent être importées séparément (voir « Importer les commandes WooCommerce plus anciennes »). Une commande déjà importée est mise à jour, jamais dupliquée.

La tâche d'arrière-plan (cron)

Les synchronisations planifiées, les tâches en file d'attente et les nouveaux essais sont exécutés par une tâche d'arrière-plan que votre hébergeur lance chaque minute. Sans elle, une synchronisation reste « en attente » dans la file. Elle est configurée une seule fois par la personne qui gère l'hébergement, dans cPanel › Tâches Cron, avec une planification toutes les minutes et une commande comme :

/usr/local/bin/php /home/ACCOUNT/public_html/app/bin/scheduler.php

Remplacez ACCOUNT par votre nom d'utilisateur cPanel. Il s'agit d'une commande serveur, pas d'une adresse web : ne l'ouvrez pas dans le navigateur.

Lire la carte de la connexion

  • Dernière synchro réussie / Dernière tentative — quand la boutique a été lue pour la dernière fois ; si la tentative est plus récente que la réussite, le dernier essai a échoué et son erreur est affichée.
  • Dernier webhook — quand la boutique a envoyé son dernier webhook. Vide signifie que les webhooks ne sont pas configurés ou n'arrivent pas.
  • File d’attente — les tâches en attente et celles en échec. Un gros import est découpé en petits lots : plusieurs lots en attente sont donc normaux juste après Synchroniser maintenant ou un import de commandes plus anciennes.

Ce qui est copié

Uniquement les clients, les commandes, les articles de commande et les produits qu'elles contiennent. Les clients invités (sans compte dans la boutique) sont inclus, identifiés par l'e-mail et le téléphone de leur commande. Les données de paiement et les mots de passe ne sont jamais copiés.

Astuce : si Synchroniser maintenant indique qu'une synchronisation est déjà en file d'attente, la demande précédente ne s'est pas encore exécutée. Vérifiez que la tâche cron tourne ; le nombre de tâches en attente dans File d’attente doit baisser en quelques minutes.

Connexion désactivée : aucune synchronisation ne s'exécute et les webhooks reçus sont ignorés jusqu'à ce que vous cliquiez sur Activer.
