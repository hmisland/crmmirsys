Modules are activated for an organization by the platform administrator (Super Admin). From Modules & Features you send an activation request instead of contacting them separately. A request never activates anything by itself.

Send a request

  1. Open Organization settings › Modules › Modules & Features, or click Request activation next to a module on the Modules page.
  2. On the module’s card click Request activation and confirm.
  3. The card shows Request pending with the request date.

Only one request per module can be pending. A module that is already active, or not offered, cannot be requested. Sending requests needs permission to edit organization settings.

After the review

  • Approved — the module is activated for your organization and becomes Active. You receive a notice under Platform messages (the bell icon).
  • Rejected — the module stays off. The notice and the card show the reason, if one was given. You can click Request again later.

Every request and decision is recorded in your organization’s history.

For the platform administrator

  1. Open Module requests in the sidebar (Platform). Pending requests are at the top, oldest first; filter by status to see the history.
  2. Approve activates the module for that organization with the usual checks. If a required module is off, or the module is disabled platform-wide, nothing changes, the request stays pending and the reason is shown.
  3. Reject takes an optional reason (up to 500 characters) that the organization will see.

The same buttons appear on the organization’s module screen (All organizations › Manage modules). A request already reviewed cannot be reviewed again.

Tip: if a module needs another one (for example Notifications needs Wallet), request both. The administrator activates the required one first.
