Les modules sont activés pour une organisation par l'administrateur de la plateforme (Super Admin). Depuis Modules et fonctionnalités, vous envoyez une demande d'activation au lieu de le contacter séparément. Une demande n'active jamais rien d'elle-même.

Envoyer une demande

  1. Ouvrez Paramètres de l’organisation › Modules › Modules et fonctionnalités, ou cliquez sur Demander l'activation à côté d'un module sur la page Modules.
  2. Sur la carte du module, cliquez sur Demander l'activation et confirmez.
  3. La carte affiche Demande en attente avec la date de la demande.

Une seule demande par module peut être en attente. Un module déjà actif, ou non proposé, ne peut pas être demandé. L'envoi de demandes nécessite le droit de modifier les paramètres de l'organisation.

Après l'examen

  • Approuvée — le module est activé pour votre organisation et passe à Actif. Vous recevez un avis dans Messages de la plateforme (l'icône en forme de cloche).
  • Refusée — le module reste désactivé. L'avis et la carte indiquent le motif, s'il a été donné. Vous pourrez cliquer plus tard sur Redemander.

Chaque demande et chaque décision sont enregistrées dans l'historique de votre organisation.

Pour l'administrateur de la plateforme

  1. Ouvrez Demandes de modules dans la barre latérale (Plateforme). Les demandes en attente sont en haut, les plus anciennes d'abord ; filtrez par statut pour voir l'historique.
  2. Approuver active le module pour cette organisation avec les vérifications habituelles. Si un module requis est désactivé, ou si le module est désactivé sur toute la plateforme, rien ne change, la demande reste en attente et le motif est affiché.
  3. Refuser accepte un motif facultatif (500 caractères au maximum) que l'organisation verra.

Les mêmes boutons apparaissent sur l'écran des modules de l'organisation (Toutes les organisations › Gérer les modules). Une demande déjà examinée ne peut pas l'être de nouveau.

Astuce : si un module en nécessite un autre (par exemple Notifications nécessite Portefeuille), demandez les deux. L'administrateur active d'abord le module requis.
