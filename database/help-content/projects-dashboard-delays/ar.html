اللوحة

افتح المشاريع ← لوحة المشاريع. تُحسب فقط المشاريع التي تراها: المشاريع النشطة والمتأخرة، والمراحل القادمة والمتأخرة، ومع وحدة المبيعات المهام المفتوحة والمتأخرة.

كيف تُقيَّم التواريخ

  • مشروع متأخر: فات تاريخ الانتهاء المتوقع والمشروع غير مكتمل أو ملغى.
  • ينتهي قريبًا / قادم: خلال الأيام الأربعة عشر القادمة.
  • مرحلة متأخرة: ما زالت مخططًا لها بعد تاريخها. مراحل المشاريع المكتملة أو الملغاة لا تكون متأخرة أبدًا.
  • مهمة متأخرة: غير منجزة أو ملغاة أو مرفوضة وقد فات تاريخ استحقاقها.

تعرض مشاريع تحتاج إلى متابعة هذه المشاريع حسب الأولوية مع السبب، ويربط مربع مشاريع بها مهام متأخرة بلوحة كانبان لكل مشروع.

رسائل التأخير

عندما يتجاوز المشروع تاريخ انتهائه المتوقع، أو تتجاوز مرحلة مخطط لها تاريخها، يتلقى مدير المشروع رسالة واحدة بالعناصر المتأخرة حديثًا. يُرسل كل عنصر مرة واحدة لكل تاريخ؛ وإذا حدّدت تاريخًا جديدًا وفات مجددًا تُرسل رسالة جديدة.

للمسؤول: تحتاج الرسائل إلى إعدادات البريد في النظام وإلى cron المجدول (app/bin/scheduler.php كل دقيقة).
