Brevo (brevo.com) خدمة بريد ثانية مدعومة. ميزتها في CRM: تعيد أحداث التسليم والارتداد والبريد المزعج وإلغاء الاشتراك، فتكتمل نتائج الحملة أكثر.

الخطوات

  1. سجّل في Brevo وأكّد حسابك.
  2. Senders, domains & IPs: أضف عنوان المرسل ووثّق نطاقك (SPF وDKIM وDMARC — دليل «توثيق نطاق الإرسال»). يجب أن يكون المرسل نشطًا.
  3. SMTP & API › API keys: أنشئ مفتاح API (يبدأ بـ xkeysib-).
  4. في CRM: إعدادات المؤسسة › مزوّدو الرسائل › البريد — Brevo: المفتاح وبريد المرسل واسمه وعنوان رد اختياري ← حفظ واختبار الاتصال.
  5. اضغط تسجيل الـWebhook لتصل أحداث التسليم إلى CRM. يتطلب ذلك تشغيل CRM عبر https://.
  6. أرسل بريدًا تجريبيًا.

ما يفحصه اختبار الاتصال

  • صلاحية المفتاح (حساب Brevo).
  • أن بريد المرسل مرسل نشط في Brevo — وإلا يظهر تحذير؛ أصلحه في Brevo قبل إرسال الحملات.
  • لا يستطيع فحص SPF/DKIM — يظهر تحذير توثيق النطاق دائمًا للتذكير.

نصيحة: يمكنك ربط Sender وBrevo معًا؛ وكل حملة بريد تختار أحدهما.
