Brevo (brevo.com) est un second service d'e-mail pris en charge. Son atout dans le CRM : il renvoie les événements de remise, rebond, spam et désinscription, pour des résultats de campagne plus complets.

Étapes

  1. Inscrivez-vous chez Brevo et confirmez votre compte.
  2. Senders, domains & IPs : ajoutez votre adresse d'expéditeur et authentifiez votre domaine (SPF, DKIM, DMARC — guide « Vérifier le domaine d'envoi »). L'expéditeur doit être actif.
  3. SMTP & API › API keys : créez une clé API (elle commence par xkeysib-).
  4. Dans le CRM : Paramètres de l'organisation › Fournisseurs de messagerie › E-mail — Brevo : clé, e-mail et nom d'expéditeur, adresse de réponse facultative → Enregistrer et tester la connexion.
  5. Cliquez sur Enregistrer le webhook pour que les événements de remise arrivent dans le CRM. Le CRM doit être servi en https://.
  6. Envoyez un e-mail de test.

Ce que vérifie le test de connexion

  • Que la clé est valide (compte Brevo).
  • Que votre e-mail d'expéditeur est un expéditeur actif chez Brevo — sinon un avertissement s'affiche ; corrigez-le chez Brevo avant les campagnes.
  • Il ne peut pas vérifier SPF/DKIM — l'avertissement sur l'authentification du domaine reste affiché en rappel.

Astuce : vous pouvez connecter Sender et Brevo ; chaque campagne e-mail choisit l'un des deux.
