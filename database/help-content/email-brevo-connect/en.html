Brevo (brevo.com) is a second supported email service. Its advantage in the CRM: it reports delivered, bounced, spam and unsubscribe events back, so campaign results are more complete.

Steps

  1. Sign up at Brevo and confirm your account.
  2. Senders, domains & IPs: add your sender address and authenticate your domain (SPF, DKIM, DMARC — see "Verifying your sender domain"). The sender must be active.
  3. SMTP & API › API keys: create an API key (it starts with xkeysib-).
  4. In the CRM: Organization settings › Messaging providers › Email — Brevo: key, sender email, sender name, optional reply-to → Save and test connection.
  5. Press Register webhook so delivery events reach the CRM. This needs the CRM to run on https://.
  6. Send a test email.

What the connection test checks

  • That the key is valid (Brevo account).
  • That your sender email is an active sender in Brevo — if not, you see a warning; fix it in Brevo before sending campaigns.
  • It cannot check SPF/DKIM — the warning about domain authentication is always shown as a reminder.

Tip: you can connect both Sender and Brevo; each email campaign chooses one of them.
