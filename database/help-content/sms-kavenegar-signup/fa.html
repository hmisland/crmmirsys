این راهنما فقط وقتی لازم است که بخواهید پیامک‌ها از حساب کاوه‌نگار خود سازمان ارسال شود. اگر از «سرویس پیامک ما» (حساب سامانه) استفاده می‌کنید، به حساب کاوه‌نگار نیازی ندارید.

مراحل

  1. به kavenegar.com بروید و ثبت‌نام کنید.
  2. در پنل، احراز هویت را کامل کنید. طبق الزامات قانونی پنل‌های پیامکی، بدون احراز هویت امکان ارسال کامل وجود ندارد.
  3. حساب را شارژ کنید (ارسال از حساب اختصاصی از اعتبار خود کاوه‌نگار کسر می‌شود).
  4. از بخش تنظیمات حساب در پنل، کلید API (API Key) را کپی کنید.
  5. شمارهٔ خط ارسال را از بخش خطوط پنل بردارید. برای پیامک به شماره‌های خارج از ایران، خط بین‌المللی جداگانه لازم است (اختیاری).
  6. در CRM: تنظیمات سازمان › پیامک ← «حساب کاوه‌نگار خودم» ← کلید API و خط ارسال را وارد کنید ← ذخیره. CRM پیش از ذخیره کلید را با کاوه‌نگار بررسی می‌کند.
  7. در همان صفحه یک پیامک آزمایشی به شمارهٔ خودتان بفرستید.

قواعد

  • کلید API رمزنگاری‌شده ذخیره می‌شود و دیگر نمایش داده نمی‌شود؛ برای حفظ کلید قبلی فیلد را خالی بگذارید.
  • کلید مثل رمز عبور است؛ اگر لو رفت، در پنل کاوه‌نگار کلید جدید بسازید و در CRM جایگزین کنید.
  • ارسال آزمایشی محدود است (به‌طور پیش‌فرض ۵ بار برای هر کاربر در ۱۰ دقیقه).

نکته: خطاهای کاوه‌نگار با پیام خود کاوه‌نگار نمایش داده می‌شوند؛ مثلاً ۴۱۸ یعنی «اعتبار کافی نیست» و ۴۱۲ یعنی خط ارسال نامعتبر یا تعریف‌نشده است.
