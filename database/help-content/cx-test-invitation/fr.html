Une invitation de test vous permet d'essayer un questionnaire sur vous-même : une vraie invitation avec un lien à usage unique est envoyée à votre propre mobile ou e-mail par l'envoi normal, pour que vous voyiez le message et la page du questionnaire comme un client.

Envoyer un test

  1. Ouvrez Satisfaction client et allez à Envoyer une invitation de test.
  2. Choisissez l'Enquête. Un questionnaire qui n'est pas encore activé peut aussi être testé.
  3. Choisissez Envoyer par : un canal configuré (SMS, e-mail ou Bale).
  4. Cliquez sur Envoyer l'invitation de test et vérifiez votre téléphone ou votre boîte mail.

Elle est envoyée au numéro mobile et à l'e-mail de votre profil. S'il en manque un, le formulaire l'indique ; ajoutez-le avec Modifier le profil. L'envoi de tests nécessite le droit de gérer Satisfaction client.

En quoi un test diffère d'une vraie invitation

  • Le message commence par [Test], l'invitation affiche le badge Test, et dans Marketing › Transactionnels sa source est « Enquête de satisfaction client (test) ».
  • Aucune commande ni aucun client n'est concerné, et un test en échec n'est pas renvoyé.
  • Quand vous répondez, le lien est consommé et la page de remerciement s'affiche, mais aucune réponse n'est enregistrée : les résultats, les moyennes et les suivis ne changent pas.
  • Jusqu'à 10 invitations de test par utilisateur et par heure.

Si le test n'est pas envoyé

  • Aucun canal d'envoi n'est prêt — configurez SMS, e-mail ou Bale dans Fournisseurs de messagerie.
  • Votre profil n'a pas d'adresse e-mail valide / de numéro mobile iranien valide — complétez votre profil.
  • Trop d'invitations de test — attendez une heure.

Astuce : pour les SMS, le message doit respecter les règles de votre fournisseur SMS. Refaites un test après chaque modification du message d'invitation.
