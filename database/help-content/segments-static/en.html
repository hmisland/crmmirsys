1. Marketing › Segments › New static segment: name and description → Save.
  2. On the segment page, under Add contacts, search by name, mobile or email.
  3. Tick the contacts and press Add selected. Contacts already in the segment are marked.
  4. To remove, tick members in the list and press Remove selected.

System rules

  • Static segments are lists of people, so creating and editing them needs both "manage segments" and access to Contacts.
  • Only contacts of your own organization can be added; a contact is never added twice.
  • A deleted contact leaves the segment automatically.
  • Search and member lists are paginated, so a segment can have any number of contacts.

Tip: if you keep adding the same kind of contact by hand (e.g. everyone with a tag), a dynamic segment will do it for you.
