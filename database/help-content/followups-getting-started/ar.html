ما هي المتابعة

المتابعة اتصال أو إجراء مخطط له مع العميل: مكالمة أو بريد أو رسالة أو اجتماع أو مهمة أو تذكير أو ملاحظة أو نوع مخصص، مع أولوية (منخفضة، عادية، عالية، عاجلة) وتاريخ استحقاق ومسؤول. يمكن ربطها بجهة اتصال أو صفقة أو عقد أو مشروع وتظهر في صفحاتها.

العمل بالمتابعات

  • المتابعات ← جديد ينشئ متابعة؛ ويمكن تصفية القائمة والبحث فيها.
  • في كل متابعة: إكمال أو إلغاء أو إعادة جدولة إلى تاريخ جديد.
  • تعرض لوحة التحكم متابعاتك القادمة.

المتابعات التلقائية (القواعد)

مع وحدة المبيعات، تنشئ المتابعات ← القواعد متابعة تلقائيًا عندما تصل الصفقة إلى مرحلة ما — مثل «اتصل بالعميل بعد يومين من العرض». يمكن للقاعدة إضافة تذكير قبل موعد الاستحقاق بدقائق، فيتلقى المسؤول رسالة تذكير بالبريد.

للمسؤول: تحتاج رسائل التذكير إلى إعدادات البريد في النظام وإلى cron المجدول (app/bin/scheduler.php كل دقيقة).
