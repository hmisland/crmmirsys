Qu’est-ce qu’un suivi

Un suivi est un contact ou une action planifiée avec un client : appel, e-mail, message, réunion, tâche, rappel, note ou type personnalisé, avec une priorité (basse, normale, haute, urgente), une échéance et un responsable. Il peut être lié à un contact, une affaire, un contrat ou un projet et apparaît sur leurs pages.

Travailler avec les suivis

  • Suivis → Nouveau en crée un ; la liste peut être filtrée et recherchée.
  • Sur un suivi : Terminer, Annuler ou Replanifier à une nouvelle date.
  • Le tableau de bord affiche vos prochains suivis.

Suivis automatiques (règles)

Avec le module Ventes, Suivis → Règles crée automatiquement un suivi quand une affaire atteint une étape — par exemple « appeler le client 2 jours après la proposition ». Une règle peut ajouter un rappel quelques minutes avant l’échéance ; le responsable reçoit alors un e-mail de rappel.

Pour l’administrateur : les e-mails de rappel exigent les réglages de messagerie du CRM et le cron du planificateur (app/bin/scheduler.php, chaque minute).
