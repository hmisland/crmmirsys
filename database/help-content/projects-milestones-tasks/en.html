Milestones

In the Milestones box of a project, add a name and a date. A milestone is Planned, Completed or Cancelled; use Edit to change it. A planned milestone whose date has passed counts as late. Adding, editing and deleting need the project edit permission and are recorded in the project history.

Tasks and progress

With the Sales module, the project page has a Tasks box: the project’s tasks with status, priority, assignees and due date, and the counts Open, Completed and Overdue. New task creates a normal task already linked to the project.

Progress = completed tasks ÷ tasks that were not cancelled or rejected. Without tasks it is 0%. The same figure appears in the project overview and in the Progress column of the projects list.

Kanban board

Kanban board in the Tasks box shows one column per task status of your organization. Pick a new status on a card and press Move. In Tasks, the Project filter lists one project’s tasks.

Tip: everyone sees only the tasks their own permissions allow, so counts can differ between colleagues.
