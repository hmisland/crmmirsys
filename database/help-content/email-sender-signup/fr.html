Sender (sender.net) est un service d'e-mail avec une offre gratuite. Le CRM utilise votre compte via son API officielle.

Étapes

  1. Ouvrez sender.net et choisissez Sign up. Utilisez si possible une adresse de votre propre domaine.
  2. Confirmez l'e-mail envoyé par Sender et complétez le court profil du compte (nom de l'entreprise et adresse — exigés par les lois anti-spam et affichés en pied d'e-mail).
  3. Dans Sender, ouvrez Settings › API access tokens et créez un jeton avec un nom reconnaissable, par ex. « CRM ».
  4. Copiez le jeton tout de suite : il est long (environ 1 000 caractères) et Sender ne l'affiche qu'une fois.
  5. Avant d'envoyer, authentifiez votre domaine (guide « Vérifier le domaine d'envoi »).

Règles

  • Collez le jeton d'un seul bloc, sans espace ni retour à la ligne. Le CRM refuse un jeton contenant des espaces.
  • Traitez le jeton comme un mot de passe : il permet d'envoyer des e-mails en votre nom. Ne le partagez pas par chat ou e-mail ; en cas de fuite, supprimez-le dans Sender et créez-en un nouveau.
  • Une organisation = un compte Sender. Chaque organisation du CRM saisit son propre jeton.

Attention : supprimer le jeton dans Sender arrête immédiatement les campagnes du CRM. Créez d'abord le nouveau jeton, enregistrez-le dans le CRM, puis supprimez l'ancien.
