A segment is a saved, reusable audience (Marketing › Segments). Instead of picking recipients again for every campaign, you choose the segment.

StaticDynamic
What it isa fixed list of contacts you pick by handrules, e.g. "city is Tabriz AND created in the last 30 days"
Changes whenyou add or remove memberscontacts change — recalculated every time it is previewed or used
Good foran invitation list, a pilot group, VIPsregular campaigns: new contacts, a city, birthdays this month

System rules

  • A segment belongs to one organization and can be used in any number of campaigns.
  • Creating, editing and deleting segments needs the "manage segments" permission; viewing and using them needs only Marketing access.
  • Seeing the matching contacts' details needs access to Contacts; otherwise you see only the count.
  • A deleted contact automatically leaves every segment.
  • Deleting a segment does not affect campaigns that already used it.

Tip: prefer dynamic segments — they stay correct by themselves. Use static ones only when the list is truly hand-picked.
