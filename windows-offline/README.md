# Mirsys CRM — نسخهٔ آفلاین برای شبکهٔ داخلی (ویندوز)

CRM روی **یک کامپیوتر** (سرور) نصب می‌شود و بقیهٔ کامپیوترهای همان شبکه با مرورگر کار می‌کنند.
به اینترنت، هاست یا cPanel نیاز ندارد. این پوشه فقط اسکریپت نصب اضافه می‌کند؛ کد CRM دست نخورده است.

## پیش‌نیاز (یک بار دانلود، روی کامپیوتر سرور)

> اگر «بستهٔ کامل» (`mirsys-crm-full`) را دارید، PHP، MariaDB و Visual C++ داخل پوشهٔ `runtime\` آماده‌اند؛ فقط `vendor\` را اضافه کنید و به بخش «نصب» بروید.

| مورد | از کجا | کجا بگذارید |
|---|---|---|
| PHP 8.1 یا بالاتر، x64، **Non Thread Safe** (zip) | windows.php.net/download | `runtime\php\` (طوری که `runtime\php\php.exe` باشد) |
| MariaDB 10.6+ برای Windows x86_64 (**ZIP**) | mariadb.org/download | `runtime\mariadb\` (طوری که `runtime\mariadb\bin\mysqld.exe` باشد) |
| Visual C++ Redistributable x64 (اگر PHP اجرا نشد) | learn.microsoft.com → "vc_redist.x64" | نصب عادی |
| پوشهٔ `vendor\` (کتابخانهٔ PDF) | از نسخهٔ فعلی سرور / کامپیوتر خودتان کپی کنید | ریشهٔ CRM، کنار `app\` |

ساختار نهایی:
```
C:\mirsys-crm\            ← ریشهٔ CRM (app, public, modules, ...)
C:\mirsys-crm\vendor\
C:\mirsys-crm\runtime\php\php.exe
C:\mirsys-crm\runtime\mariadb\bin\mysqld.exe
C:\mirsys-crm\windows-offline\install.bat
```
مسیر ساده و بدون فاصله/حروف فارسی مطمئن‌تر است.

## نصب
۱. روی `windows-offline\install.bat` کلیک راست → **Run as administrator**. کارها:
   ساخت `php.ini`، راه‌اندازی دیتابیس (فقط روی همین کامپیوتر، پورت 3307)، ساخت دیتابیس `crm` با رمز تصادفی،
   ساخت `.env`، ساخت جدول‌ها، باز کردن پورت **8080** در فایروال، و زمان‌بندی کارهای پس‌زمینه (هر دقیقه).
۲. `windows-offline\start.bat` را اجرا کنید (پنجره را نبندید). نشانی شبکه را نشان می‌دهد، مثلاً `http://192.168.1.10:8080`.
۳. در مرورگر **ثبت‌نام** کنید (سازمان شما ساخته می‌شود و شما مدیر سازمان می‌شوید).
۴. `windows-offline\make-superadmin.bat` را با ایمیل همان حساب اجرا کنید — آن حساب سوپرادمین می‌شود
   و **همهٔ ماژول‌ها** برای سازمان فعال می‌شوند.
۵. همکاران را از «تنظیمات سازمان ← تیم» اضافه کنید؛ آن‌ها با نشانی شبکه وارد می‌شوند.

## کار روزانه
| کار | فایل |
|---|---|
| اجرا | `start.bat` |
| توقف | `stop.bat` |
| کارهای پس‌زمینه (یادآوری وظایف، پیگیری‌ها، هشدار تأخیر پروژه، صف پیام) | خودکار، Task Scheduler: `MirsysCRM-Cron` |

## پشتیبان‌گیری
از این دو پوشه منظم کپی بگیرید (بهتر است وقتی `stop.bat` اجرا شده):
`runtime\data\` (دیتابیس) و `storage\` (فایل‌های بارگذاری‌شده). فایل `.env` را هم نگه دارید.

## به‌روزرسانی
فایل‌های کد جدید را روی ریشهٔ CRM کپی کنید (به `runtime\`، `.env`، `storage\` و `vendor\` دست نزنید)
و دوباره `install.bat` را با Run as administrator اجرا کنید؛ داده و تنظیمات حفظ می‌شوند و جدول‌های جدید ساخته می‌شوند.

## محدودیت‌ها
- وب‌سرور داخلی PHP استفاده می‌شود: برای یک دفتر کوچک (حدود ۱۰ کاربر هم‌زمان) مناسب است.
  برای تعداد بیشتر، همین پوشه را پشت Apache/IIS بگذارید.
- ایمیل خاموش است (`MAIL_DRIVER=log`، نامه‌ها در `storage\mail` ذخیره می‌شوند). برای ارسال واقعی، تنظیمات SMTP را در `.env` بگذارید.
- ارسال پیامک، ووکامرس و درگاه‌ها به اینترنت نیاز دارند.

## لایسنس
بدون لایسنس معتبر فقط صفحهٔ لایسنس (`http://localhost:8080/__license`) نمایش داده می‌شود.

**مشتری:** بعد از نصب، صفحه **کد نصب** این کامپیوتر را نشان می‌دهد (مثل `MCRM-XXXX-XXXX-XXXX`).
آن را برای فروشنده می‌فرستد و فایل لایسنس دریافتی را در همان صفحه بارگذاری می‌کند.
کد نصب به همین کامپیوتر بسته است؛ کپی پوشه روی کامپیوتر دیگر لایسنس را نامعتبر می‌کند.

**فروشنده (فقط روی کامپیوتر خودتان، با کلید خصوصی):**
```
php windows-offline\license-tool.php make C:\keys\private-key.pem MCRM-XXXX-XXXX-XXXX "نام مشتری" 10 365
```
`10` = حداکثر کاربر فعال، `365` = روز اعتبار (صفر یا خالی = نامحدود). خروجی: `license-MCRM-....json`.
تمدید یا افزایش کاربر = صدور فایل جدید با همان کد نصب.

**سقف کاربران:** کاربران با وضعیت «فعال» شمرده می‌شوند. وقتی به سقف برسید، ثبت‌نام، افزودن کاربر
و فعال‌کردن دوبارهٔ کاربر انجام نمی‌شود؛ با غیرفعال کردن یک کاربر جا باز می‌شود.

**کلید خصوصی (`private-key.pem`)** فقط پیش فروشنده می‌ماند — هرگز در بستهٔ مشتری یا گیت نگذارید.
برای کلید تازه: `php license-tool.php keygen C:\keys` و فایل `public-key.pem` جدید را جای
`windows-offline\license\public-key.pem` بگذارید (لایسنس‌های قبلی دیگر کار نمی‌کنند).
